ARCHITECTURE

Deterministic first. AI only where ambiguity actually matters.

V1.0 can semantically review unusual assignment briefs and reconsider low-confidence routing. It cannot silently remove requirements, mark evidence verified, or override the Submission Gate.

3 · WHAT AI CAN DO

Semantic assistance at two high-value choke points

ASSIGNMENT ADAPTERSemantic review

Find likely omissions, subtle constraints, unclear wording and useful task additions after the deterministic plan already exists.

Open Adapter →
I'M STUCK ROUTERLow-confidence reconsideration

When deterministic routing is ambiguous, ask AI to recommend one existing DA.OS workflow without solving the assignment itself.

Open Router →
NOT ALLOWEDNo silent authority

LOCAL SETUP

Run V1.0 securely

cd da-os
export AI_GATEWAY_API_KEY="your_gateway_key"
# optional: export DAOS_AI_MODEL="openai/gpt-5.6-sol"
python3 server.py

Then open http://127.0.0.1:8000/ai.html, enable AI reasoning, and test the connection.
